# AI World Engine 世界数据结构 v0.1

## World State 是什么

World State（世界状态）是某一时刻世界中已确定事实的结构化记录。它保存世界的时间、天气、角色、地点、关系、记忆和全局指标，是后续行动与变化的共同依据。

## 核心对象

- **Player（玩家）**：玩家在世界中的角色数据，包括身份、特征、当前位置、物品、关系和记忆。v0.1 保留身份字段为空，未来由 AI 根据玩家的自然语言创建角色。
- **NPC（非玩家角色）**：持续存在于世界中的角色，包含身份、性格、目标、情绪、知识、关系和记忆。NPC 的回应应基于这些已有状态。
- **Location（地点）**：世界中的可访问区域，记录地点名称、类型、描述以及与其他地点的连接关系。
- **Memory（记忆）**：玩家或 NPC 对过去事件的持久记录。记忆让角色能够参考此前发生的事情，并保持行为与关系的连续性。
- **Global State（全局状态）**：影响整个世界或较大范围的共享指标，例如村庄安全度、龙类活动、食物储备和风暴强度。

## 为什么 AI 必须受到 World State 约束

大模型只根据当前文本生成内容时，可能随意增加事实、遗忘既有事件，或让同一角色和地点前后矛盾。AI World Engine 因此不能把模型输出直接当作世界事实，而应以 World State 作为可信来源：AI 的行动与叙事需要读取当前状态、遵守已存在的事实和规则，并且只有经过校验的结果才能更新状态。这样才能让开放世界保持一致、可追踪且能够持续演化。
